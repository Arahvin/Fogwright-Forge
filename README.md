# Fogwright Forge

A character builder for D&D 2024 (SRD 5.2) in the Ninth World, in the spirit of D&D Beyond. It runs in the browser with no server: open `index.html`, or use the GitHub Pages link.

- **Classes, spells, gear:** the 12 SRD 5.2 classes, their level 1 choices, spells and starting equipment.
- **Species:** the Ninth World species of our campaign (Humans, Grafted, Warbred, Firstborn, Lightborn, Ashmaw, Stonebound, Tinkerfolk), 2024 rules unchanged. No Goliaths or Halflings.
- **Artificer:** from the 2024 Unearthed Arcana playtest (`data/artificer.js`), with all four subclasses, the spell list and the Homunculus Servant spell. Only numbers and short summaries in our own words; the full text is in the UA PDF.
- **Backgrounds:** all 16 from 2024. The 4 SRD ones have full text; the 12 Player's Handbook ones only carry their numbers.
- **House rules:** shins for money, the cypher limit (PB + 1), GM intrusions, and the Glaive / Nano / Jack / Tender labels.
- **Export:** the Sheet tab's *Export for Fogwright VTT* writes a `.json` that the VTT imports as-is (GM: Sheets tab → Import). *Save Forge file* keeps the full character, to back up or move to another computer.

Opened as a file or from GitHub Pages, characters are kept in the browser (localStorage). Served from the GM's PC (below), they are kept on that PC with player accounts. The version is in the page footer.

## Serve it from your PC (like the VTT)

Double-click `start.bat` (needs Python, same as the VTT). Players open `http://<your Hamachi IP>:8766/`. Only this PC and Hamachi addresses (25.x) are let in. Open the port for Hamachi once, in PowerShell as administrator:

```
New-NetFirewallRule -DisplayName "Fogwright Forge (Hamachi)" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8766 -RemoteAddress 25.0.0.0/8 -Profile Any
```

PT: faz duplo clique em `start.bat`; os jogadores abrem `http://<IP do Hamachi>:8766/`.

### Accounts

When served this way, everyone signs in. The GM signs in with the name `GM` and the GM key shown in the server window (stored in `forge-data/config.json`). On the **Players** page the GM adds each player with a name and password, and can reset a password by saving the same name again. A player sees only their own characters; the GM sees all of them and can move a character to another player with the **Owner** list. Players can change their own password.

Characters are saved in `forge-data/characters/`, one `.json` file each. Back up the `forge-data` folder. It is never served to the browser and is not in git. Characters made earlier in a browser show up with a button to send them to the account.

## PT

Construtor de personagens para D&D 2024 no Nono Mundo. Abre o `index.html` (ou o link do GitHub Pages), cria a personagem e, no separador *Ficha*, carrega em *Exportar para o Fogwright VTT*. No VTT, o Mestre importa esse `.json` no separador Fichas.

## Data

`data/srd.js` and `data/species.js` are generated by `tools/make_data.py` (see its docstring). `data/extra.js` is written by hand.
